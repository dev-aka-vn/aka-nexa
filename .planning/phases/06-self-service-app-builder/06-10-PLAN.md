## Phase Goal

**As a** department admin, **I want to** build, secure, and publish a working app end-to-end, **so that** I need no engineering ticket and no platform admin's help.

<objective>
Close gap G-06-8: the signer-facing Form Renderer — the surface the product's core value rests on — renders the authored form as a collapsed full-width stack of browser-default inputs.

The root cause is identical to G-06-6 and was proven independently of the designer: `@formio/js` 5.x wires in the Bootstrap 5 template set by default, the renderer imports only the engine's own stylesheet, and Bootstrap's stylesheet is installed but imported nowhere. Plan 06-09 already produced the one shared mechanism and both byte-identical artifacts; this plan consumes the renderer copy and proves it on a real rendered page.

Purpose: the renderer had no browser-level test at all — its specs asserted import strings, which is why an unstyled signer form shipped. This plan makes the renderer browser-loadable (it has no dev server and no bundler config today) and adds the computed-layout guard that could not have missed this defect, then records the new coverage in the UAT.

Output: a renderer dev-server config, the scope class and stylesheet import on both renderer pages, a per-project Playwright harness that boots each app's dev server, the renderer layout guard, and the UAT row that closes the coverage hole.
</objective>
