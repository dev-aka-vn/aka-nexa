## Phase Goal

> Same derivation as plan 01: the ROADMAP goal is not in user-story format, so it is restated, not invented. **As a** platform engineer, **I want to** freeze the read-link claim shape and the JEV wire contract as strict, version-named schemas with mechanical key-set tests, **so that** adding a claim or field later fails CI instead of silently invalidating every outstanding link or invalidating the provider conformance suite.

<objective>
Freeze the two contracts this phase exists to protect. Ship `packages/contract/src/jev/v1/` as
`.strict()` Zod schemas with `z.toJSONSchema()` as the published artifact, add exactly the two D-23
fields (`choice.verified`, request `state.force_clarification`), publish the `JevProvider` interface
with `RuleBasedProvider` named as the terminal fallback, freeze the fifteen-claim `ReadLinkClaims`
schema, and add the supporting shapes that later phases import without re-deciding: the token-class
table, the `user`/`link` rate-limit key, the connector idempotency declaration, and the IM event
envelopes.

Purpose: RTE-10 and LNK-07 are two of the four irreversible commitments. "Frozen" is mechanical
(D-24): each schema is `.strict()` **and** has a test asserting its exact sorted top-level key set
against a literal array, so a removed key (which `.strict()` cannot see) still fails CI, and an
added key fails CI with a diff. The version name (`1.0`) makes a deliberate break a visible edit.

Output: versioned contract schemas, published JSON Schemas, and the frozen-key-set tests that make
future additions loud.
</objective>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| untrusted link (browser) → claim verification | The claim schema is the only thing deciding which link payloads are well-formed. |
| JEV provider → platform | Provider output crosses into routing; an out-of-shape or abstaining choice must be handled by contract. |
| caller → rate-limit key | If an address could be a key scope, per-IP limiting would be expressible and AUD-10 would regress. |
| connector → downstream system | The idempotency declaration is the contract that stops a blind re-send. |
