## Phase Goal

**As a** department admin, **I want to** build, secure, and publish a working app end-to-end, **so that** I need no engineering ticket and no platform admin's help.

<objective>
Close gap G-06-6: the FormIO 5.6.1 designer renders the correct Bootstrap 5 class vocabulary with no Bootstrap stylesheet anywhere in the document, so the canvas and preview render as unstyled HTML.

This plan builds ONE shareable mechanism — a checked-in, selector-prefixed (scoped) Bootstrap 5 stylesheet produced by a dependency-free Node generator, plus a drift guard — and consumes it at the designer's two FormIO mount points. The renderer consumes the same mechanism in plan 06-10, which is why the generator emits both copies here: the root cause is shared, so the fix must be one artifact, not two divergent local patches.

Purpose: a class-name assertion is what let this gap ship. The guards this plan adds invert the measured symptoms — an empty `--bs-primary`, a row computing `display: block`, columns both spanning the full canvas, a form-control carrying the browser's default 2px inset border and 1px/2px padding — into computed-style assertions that can only pass when the stylesheet is actually present and actually reaching the FormIO subtree.

Output: the generator and its drift-guard spec, the two byte-identical scoped stylesheets, the designer canvas and preview consumption sites, the two app-builder Playwright guards, and the artefact-spec rework that replaces the class-name test.
</objective>

    - For every rule, split the selector on commas and prefix each part with the scope root selector and a descendant combinator, so a bare Bootstrap class rule becomes reachable only beneath the scope root.

    - Keep the universal-selector box-sizing rule, transformed like any other — it is load-bearing for the grid.
