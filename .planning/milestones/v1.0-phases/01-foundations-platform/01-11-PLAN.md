What failed was test 1 — that a human can *reach* that state from a clean checkout using only the project's own words. `SERVICE_NAME` is a required boot key with no default, and the three npm scripts do not supply it, so "independently runnable" is not yet true for a reader. What never shipped is the *enumeration* of what it validates — six keys in one file, two in another, with no example file presenting them as a set. G1's own `root_cause` says exactly this: "Nothing owned writing the env contract down." `.env.example` is that missing artifact, and `tooling/onboarding.spec.ts` asserts it against `APP_CONFIG_KEYS` so it cannot drift from the schema again.
