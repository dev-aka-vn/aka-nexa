# Phase 9 — UI Design Contract

> Visual and interaction contract for frontend phases. Generated by gsd-ui-researcher, verified by gsd-ui-checker.

---

> **Contract constraints (read first).**
> 1. **`prototypes/mockup.html` is the single source of truth** for layout, information
>    architecture, copy, colour, type and spacing (AGENTS.md "UI Design"). Reuse its `:root`
>    token set verbatim — a colour or typeface not derived from it is a **defect, not a
>    preference** (rule 1).
> 2. **A frozen contract beats the mockup** (rule 2) — and in Phase 9 the arrow runs the other
>    way at least once: the mockup's state list `["draft","published","deprecated","archived","purged"]`
>    (`mockup.html:1227`) is *stricter* than the frozen enum
>    (`packages/contract/src/builder/publish.contract.ts:82`), so D-13 **amends the contract to
>    match the mockup**. Where `packages/contract/` and the mockup disagree after that amendment,
>    the contract wins and the mockup is the thing that is wrong (F-3).
> 3. **Absence is not permission** (rule 3). The mockup does **not** depict an Access Review page
>    or nav entry, a purge **confirmation** modal, the five structured audit filters, the archived
>    marking on the Submissions scope, or the 30-day grace-period status callout. Every such gap is
>    listed in [Mockup Amendments](#mockup-amendments) or
>    [Undepicted Surfaces](#undepicted-surfaces--checkpointhuman-verify) and carries
>    `checkpoint:human-verify` — do **not** improvise a layout for them.
> 4. **Phase-9 UI scope — six deltas only:** (a) Audit Log **five structured server-side filters**
>    (`user`, `app_id`, `action`, `from`, `to` — AUD-05/D-10); (b) the **`App` and `IP` audit
>    columns** served and rendered (AUD-05/AUD-02, D-09); (c) **`Export JSON Lines`** on the Audit
>    Log (AUD-06/D-11); (d) a **new global-admin `#/access-review` route** (AUD-07/D-12, undepicted);
>    (e) **archived marking** in the existing Submissions scope (AUD-09/D-14, undepicted);
>    (f) the **Purge confirmation + grace affordances** and the `purged` state badge
>    (AUD-08/D-13). Out of UI scope: **OBS-03, OBS-06..OBS-10** (Prometheus, Grafana, k6 and
>    runbooks are repo artifacts — no console surface exists or is invented for them), the
>    **Retention policy** and **Deprecation notice** cards (no Phase-9 requirement changes them),
>    and every renderer (`status.html`/`view.html`/`edit.html`) surface.

| sm | 8px | Compact element spacing, badge/pill gaps |
| md | 16px | Default element spacing, `.toolbar` `margin-bottom:16px`, button padding |

| 3xl | 64px | Page-level spacing (`.view` bottom padding) |

  4/8/16/24/32/48/64 scale above.

## Typography

| Role | Size | Weight | Line Height |
|------|------|--------|-------------|
| Body | 14px | 400 | 1.5 |
| Label | 12.5px | 600 | 1.4 |
| Heading | 16px | 600 | 1.3 |
| Display | 25px | 600 | 1.2 |

**Weights: exactly two — regular (400) and semibold (600).** New Phase-9 surfaces use only
these. `chrome.css` already contains 500/700 in a few inherited places (`.step .dot` 700,
`.stat .k` 500, `.badge` 600); **do not add more.**

**Anchors to shipped values** (so nothing is invented):

- Display = `.page-head h1` `25px`/`600`/`1.2` — `Audit Log`, `Access Review`.
- Heading = `.card-head h2` `15.5px` and `.empty h3` `16px` — `Lifecycle state`, empty-state headings.
- Body = `.field > label` `13.5px`, filter inputs `.search input`/`.input` `14px`, `.callout`
  `13.5px`, table cells — all 400 unless a `.cell-strong` or `.step .lbl`.
- Label = `.pill-mono` `12px`, `.badge` `12px`, `.helper`/`.rc-d` `12.5px`. **Secondary/helper
  text renders at 12.5px weight 400.**
- Headings + display use `--display` (Space Grotesk); body uses `--sans` (IBM Plex Sans);
  timestamps, ids, `ip`, `request_id`, `execute_after`, JSON use `--mono` (IBM Plex Mono).

## Color

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `--canvas #f6f8fa` | Page/workspace background |
| Secondary (30%) | `--surface #ffffff` (+ `--surface-2 #f0f3f7`) | Cards, top header, inputs, table header, `pill-mono`, `card-foot` |
| Accent (10%) | `--accent #0f9d8f` (hover `--accent-strong #0b7d72`, tint `--accent-soft #e4f5f2`) | see reserved-for list |
| Destructive | `--red #c0392b` (`--red-soft #fdecea`) | Destructive actions and failure states only |

**Accent reserved for** (exhaustive list — never "all interactive elements"):

1. Primary CTAs — `.btn-primary` (`Publish now`, save/publish confirms).
2. Focus rings — `:focus-visible`, `.input:focus`/`.select:focus` glow, `.search input:focus`.
3. The **active** editor tab and the active nav affordance.
4. Checked `.switch .track`, selected `radio-card` (`.sel`), `.radio-card input` accent.
5. `.callout-accent` — the lifecycle status note for draft/published/deprecated/purged.
6. The active `.step.now .dot` (the current lifecycle state) and `.meter` fill.
7. `a { color: --accent-strong }` link text.

**Semantic scales are status, not decoration:**

- `--green #2f855a` — `badge-published`, `step.done`, completed.
- `--amber #b7791f` — `badge-deprecated`, draft/attention, `callout-warn`.
- `--blue #2b6cb0` — `badge-pending`, `callout-info` (the archived status note).
- `--violet #6b5bd2` — `badge-archived` (the archived marking, U-3).
- `--red #c0392b` — `btn-danger` (`Purge`), `badge-purged`, `failed`, `callout-danger`, `.invalid`.

Never introduce a colour or typeface outside these tokens (AGENTS.md rule 1).
