## Typography

Font stack complies with `FRM-07` (no external fonts). Prioritizes system fonts; preserves typeface intent (Space Grotesk display, IBM Plex Sans body, IBM Plex Mono code) via well-known system fallbacks.

| Role | Size | Weight | Line Height | Notes |
|------|------|--------|-------------|-------|
| Body | 16px | 400 | 1.55 | Base body size. Helper/error text 12.5px where needed. |
| Label | 14px | 600 | 1.4 | Form labels and microcopy. |
| Heading | 20px | 600 | 1.2 | Consolidates all headings under 2 weights (400/600). |
| Monospace | 12.5px | 400 | 1.4 | Code/IDs via system monospace. |

Font family (system-first, CSP-safe):
```css
--sans: system-ui, -apple-system, "Segoe UI", Roboto, Inter, "Helvetica Neue", Arial, sans-serif;
--display: system-ui, -apple-system, "Segoe UI", Inter, "Helvetica Neue", Arial, sans-serif;
--mono: ui-monospace, SFMono-Regular, Menlo, Monaco, Consolas, "Liberation Mono", "Courier New", monospace;
```

> **Note:** Space Grotesk/IBM Plex cannot be loaded from Google Fonts under FRM-07. Self-hosting woff2 is a future option if required, but not introduced in Phase 2. The system stack preserves readability and meets WCAG 2.1 AA intent.

## Copywriting Contract

Derived from SC#3–SC#5, LNK-11, IM-08, and UI states observed in mockup (empty/error/callouts/toasts). All copy is plain language, actionable, and avoids leaking internal system details.

| Element | Copy | Source/Notes |
|---------|------|-------------|
| Primary CTA | "Submit request" (verb + noun) | Maps to submission action (Phase 2 completes loop). May be contextual per app if needed, but default is specific and actionable. |
| Empty state heading | "No fields to display" | Applies if form schema is empty/unexpected (defensive). |
| Empty state body | "This form has no fields configured yet. Contact your admin to update the form." | Next step is actionable; avoids exposing internal schema details. |
| Loading state | "Submitting…" (button loading text) | Uses `.btn.is-loading` pattern; button shows spinner, text hidden accessibly. |
| Validation error (general) | "Please fix the highlighted fields." | Toast/title when submit blocked by validation (matches mockup `toast` pattern). |
| Field validation error | "This field is required." / "{constraint message}" | Inline `.error-text`; specific to constraint (required/pattern/min/max). |
| Expired link (LNK-11) | "This link has expired. Request a new link in Slack to continue." | Directly satisfies LNK-11; renderer cannot deep-link to specific thread (token lacks conversation ref per 02-CONTEXT D-41), so generic actionable guidance. |
| Invalid/used link | "This link is no longer valid. It may have been used already or revoked." | Covers LNK-01 (single-use), LNK-03 (double-consume), LNK-04 scenario; distinct from expired. |
| Denied/permission | "You don’t have permission to submit this form. Check your permissions or contact your admin." | Aligns with SC#4 (denial names missing permission in chat path; browser path gives clear, actionable message). |
| Rate limited | "Too many requests. Please wait a moment and try again." | Aligns with SC#4 rate limit clear message. |
| Submission success (browser confirmation) | "Submitted successfully. You’ll receive confirmation in Slack." | Distinct success state; reinforces same-thread confirmation (SC#1/IM-08). |
| Submission failure | "Submission failed. Try again or contact your admin if the problem continues." | Distinct, actionable per SC#5. |
| Unmapped user (defensive) | "Your Slack account isn’t linked yet. Follow the instructions in Slack to finish setup." | Defensive fallback if renderer loads without resolution context (SC#3 is chat-side; avoids raw error). |

Destructive actions: **none** in Phase 2 (no delete/archive actions on renderer). No destructive confirmation required.

## Implementation Notes (non-binding guidance)

- **CSP compliance:** Do not add `<link>` to fonts.googleapis.com or external stylesheets. If web fonts are introduced later, self-host as woff2 under same origin.
- **FormIO CSS:** Load `formio.form.min.css` (or subset) from same origin. Bootstrap 5 is bundled; avoid pulling additional CDN assets. Note FormIO 5.x defaults to Bootstrap 5 templates (STACK.md 9.3).
- **Token transport (D-41):** JWT in URL fragment `#t=`; SPA reads fragment, verifies with public key (jose), fetches schema, posts token in Authorization header on submit. No cookies (FRM-06).
- **Token lifecycle (D-42):** `DAT-08` validation → `GETDEL` consume → write. Retry possible after validation failure on same loaded page.
- **Prefill (D-44–D-47):** Server-side prefill from closed enum (employee code, department, search email). Per-field mode: `prefill` renders `readonly`; `prefill-editable` editable. Declaration lives in FormIO schema (versioned).
- **Error states:** Render distinct browser messages per Copywriting table (expired/invalid/denied/rate-limited/submission failure). Slack-side messages (SC#3/SC#5) remain chat-side.
- **No chatbot UI:** Renderer is form surface only (product is form+integration pair).
